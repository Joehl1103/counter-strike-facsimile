# Environment texture sources

These 1K diffuse and OpenGL normal maps are CC0 assets from Poly Haven:

- `large_sandstone_blocks`: https://polyhaven.com/a/large_sandstone_blocks
- `plastered_stone_wall`: https://polyhaven.com/a/plastered_stone_wall
- `cobblestone_floor_08`: https://polyhaven.com/a/cobblestone_floor_08
- License: https://polyhaven.com/license

The runtime uses metre-based UV projection so wall courses and paving retain a consistent physical scale.
