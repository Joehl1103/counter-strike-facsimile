# Vanguard character asset

`vanguard.glb` is a local copy of the Three.js `examples/models/gltf/Soldier.glb`
sample, generated from Adobe Mixamo's Vanguard character. The binary includes
its diffuse and normal textures plus Idle, Walk, Run, and T-pose clips.

- Upstream sample: https://github.com/mrdoob/three.js/blob/r185/examples/models/gltf/Soldier.glb
- Three.js license: https://github.com/mrdoob/three.js/blob/r185/LICENSE
- Mixamo usage FAQ: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
- Local SHA-256: `dfb230fc1f942f259dd00281a1186953ad602fc5d69067ce63e24b2aa439736b`
- Added to this project: 2026-09-04

These links record the binary's provenance, the upstream repository license,
and Adobe's published Mixamo usage guidance. Keep this note with the binary
when the asset is redistributed.
