# Project instructions

Use existing Linear JKH issues in the Counter-Strike 1.6 project. Read the issue,
parent and dependencies before implementation. Preserve approved scope and
criteria. Follow [AGENT_WORKFLOW.md](AGENT_WORKFLOW.md).

Never publish private history, local archives or raw/editable third-party assets.
Game imports require a separate provenance and publication review. No game
acceptance is established by this delivery scaffold.

## Project-specific PR authorization

Joseph's 2026-09-17 instruction removes the separate approval requirement for
creating/editing PRs and their Acceptance Criteria in this project. An agent must
first have authorization for the underlying task and its scope. For that task,
the agent may prepare, push and open an issue-linked PR and write or update
verifiable criteria without a second confirmation. This exception applies only
to PR creation and editing; it does not authorize new work or a merge.

Record the authorized scope and actual evidence. Required CI, independent review
and protected merge rules still apply to every PR. Creating a PR or editing its
checklist cannot satisfy or bypass those gates. This instruction does not authorize
publishing excluded game assets/history, issue closure or hosting.
